# Leo — голосовий асистент для Android українською

Leo — особистий голосовий ШІ-асистент для Android. Розуміє українську, відповідає голосом і виконує дії на телефоні: відкриває програми, будує маршрути, вмикає музику, дзвонить, пише в месенджери, читає непрочитані повідомлення й відповідає на запитання.

Мозок — [Google Gemini API](https://ai.google.dev/) з function calling, голосова розмова — Gemini Live (двобічний аудіопотік через WebSocket).

## Можливості

**Розмова**
- Жива голосова розмова з перебиванням, як у телефонному дзвінку; триває, доки не скажете «бувай»
- Пробудження фразою «Привіт, Лео» — офлайн-розпізнавання через [Vosk](https://alphacephei.com/vosk/)
- Віджет на головному екрані, плитка у швидких налаштуваннях і напівпрозоре вікно поверх будь-якої програми
- Текстовий чат з історією

**Дії на телефоні**
- Відкрити програму (нечіткий пошук, транслітерація, скорочення на кшталт «YT Music»)
- Маршрут і пошук місць у Google Maps, збережені місця («додому», «на роботу»)
- Музика в YouTube Music: пісня, виконавець, альбом, плейлист; пауза, далі, гучність
- Дзвінки й SMS з пошуком контакту з урахуванням відмінків («подзвони Олегу»)
- Повідомлення в Telegram, WhatsApp, Viber, Instagram, Discord
- Читання непрочитаних повідомлень зі сповіщень, ігнорування ботів і розсилок

**Відповіді на запитання**
- Пошук Google, погода, питання до програми Claude з озвученням відповіді
- «Що на екрані?» — знімок екрана й аналіз через Gemini vision

**UI-агент**
- Через Accessibility Service читає екран і натискає, вводить текст, гортає — до 20 кроків на завдання

## Безпека

- **Підтвердження дій.** Надсилання повідомлень і дзвінки виконуються лише після вашого «так». Модель не може обійти підтвердження: потрібен одноразовий токен, ті самі аргументи й ваша репліка між запитом і дією.
- **Заборонені зони.** UI-агент не працює в банківських програмах, менеджерах паролів і під вікном біометрії; ризиковані натискання потребують підтвердження.
- **Приховування даних.** Номери карток, IMEI, MAC та IP-адреси вирізаються з опису екрана, перш ніж він потрапить у модель. У списку контактів модель бачить лише частково приховані номери.
- **Чужі чернетки.** Служба автонадсилання бачить лише п'ять месенджерів і не чіпає текст, який ви не підтвердили.

## Вимоги

- Android 11 (API 30) або новіший, 64-бітний ARM-процесор (`arm64-v8a`). Розроблялося й перевірялося на Pixel 8.
- Ключ Gemini API — безкоштовний з [Google AI Studio](https://aistudio.google.com/apikey).
- Android Studio і JDK 17+ для збирання.

## Збирання

1. Клонуйте репозиторій і відкрийте його в Android Studio.
2. Додайте свій ключ у файл `local.properties` у корені проєкту (файл не потрапляє в git):
   ```properties
   GEMINI_API_KEY=ваш_ключ
   ```
3. Зберіть і встановіть:
   ```bash
   ./gradlew installDebug
   ```
4. Запустіть тести:
   ```bash
   ./gradlew testDebugUnitTest
   ```

## Перше налаштування

Після першого запуску Leo попросить дозволи (мікрофон, контакти, дзвінки, SMS, сповіщення). Щоб усе працювало, у налаштуваннях Leo також:

- увімкніть **дві служби спеціальних можливостей**: автонадсилання повідомлень і UI-агента;
- надайте **доступ до сповіщень** — для читання непрочитаних повідомлень;
- завантажте **українську модель Vosk** — для пробудження «Привіт, Лео»;
- заповніть розділ **«Про мене»** — це контекст для асистента.

## Структура

```
app/src/main/java/com/dmytro/leo/
├── brain/          # клієнт Gemini, цикл агента, системний промпт, Gemini Live
├── voice/          # мікрофон, відтворення, голосова сесія
├── wake/           # пробудження «Привіт, Лео» (Vosk)
├── tools/          # інструменти, які викликає модель (по класу на можливість)
├── data/           # контакти, програми, збережені місця, плейлисти, чати
├── messages/       # непрочитані повідомлення зі сповіщень
├── accessibility/  # автонадсилання й UI-агент
├── assistant/      # вікно асистента поверх інших програм
├── widget/         # віджет і плитка швидких налаштувань
└── ui/             # екрани Compose: чат, налаштування
```

Кожна нова можливість — це клас, що реалізує `Tool`, зареєстрований у `ToolRegistry`.

## Стек

Kotlin · Jetpack Compose · Coroutines · OkHttp · kotlinx.serialization · Gemini API / Gemini Live · Vosk

## Застереження

Це особистий проєкт, налаштований під один телефон і конкретні програми: YouTube Music у збірці RVX, Pixel Weather, Telegram та інші. На інших пристроях окремі функції можуть потребувати доробки. Програма не публікується в Google Play — APK встановлюється напряму.
